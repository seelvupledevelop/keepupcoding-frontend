Terms of Service & Privacy Policy

Last Updated: September 4, 2026

1. Acceptable Use

You agree not to use the service for any illegal, harmful, or infringing activity, including generating content that violates laws, regulations, or third-party rights. We strictly enforce guardrails to prevent the generation of malicious code, PII extraction, and abusive language.

2. Billing & Refunds

Access is prepaid via a token ledger. Consumed tokens are non-refundable. Unused prepaid balance may be refunded at our discretion, but consumed tokens cannot be reclaimed.

3. Data Privacy (Zero Retention)

We do not store, log, or use your prompts or outputs to train any model. All data is processed in-memory (via Redis token buckets and Cloudflare edge workers) and discarded instantaneously after the inference request completes. We do not sell your telemetry data.

4. Limitation of Liability

KeepUpCoding provides the API gateway “as is” and “as available.” To the maximum extent permitted by law, we are not liable for indirect, incidental, consequential, special, or punitive damages arising from your use of the service or upstream API outages.

KeepUpCoding MCP Server

Model Context Protocol

Connect AI coding assistants (Claude Code, Cursor, Windsurf, and any MCP-compatible client) to the model catalog through your KeepUpCoding API key. The server speaks the Model Context Protocol and exposes the platform as tools your assistant can call.

Your API key is shown only once when created. Store it in a secure secret manager — never commit it to a repository.
1. Create an API key

Sign in, open and create a key. Give it a model allowlist and a monthly cap to bound spending.

2. Register the MCP server

Add this entry to your client's MCP configuration. Keep the key in an environment variable, not in the config file.

3. Or run it standalone (npx)
What the server exposes
keepup_list_models — list models available to your key with pricing
keepup_chat — send a chat completion (streaming supported)

Requests are metered and billed against your prepaid balance exactly like direct API usage.
